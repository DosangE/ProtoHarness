# Chain Rush — UI 아트 가이드

작성: 2026-10-20. 대상: Unity 6 / URP, 기존 OnGUI 화면.
상태: 디자인 문서. 이 문서 작성으로 UI 코드나 씬을 변경하지 않는다.

## 1. 방향과 적용 기준

짙은 남청색 패널, 민트색 선택 표시, 흰색 타이포그래피로 경기장과 장갑 러너의 인상을 연결한다. 주행 화면은 중앙 시야를 비우고, 정보는 가장자리와 하단에 모은다. 배경 장식의 민트 발광은 작은 면적에만 쓴다. 앵커·봉·체인의 민트 신호를 경기장 장식이 가리지 않게 한다.

아래 좌표 표는 읽은 코드의 현재 배치다. 이후 제안은 별도로 표시한다. M2-c 작업 중 소스가 바뀌므로 구현 담당자가 적용할 때 해당 메서드의 최신 내용을 확인한다.

참고 소스:
- `Assets/_Project/Scripts/Runtime/ChainRush/Flow/TitleScreen.cs:44` — 글꼴·스타일, `:70` — 타이틀 배치.
- `Assets/_Project/Scripts/Runtime/ChainRush/Flow/LobbyMenu.cs:333` — 글꼴·스타일, `:361` — 로비 배치, `:393` — 러너 능력치, `:410` — 선택 행.
- `Assets/_Project/Scripts/Runtime/ChainRush/ChainRushHud.cs:53` — 글꼴·스타일, `:85` — 화면 배율, `:125` — 헤더, `:180` — 주행 정보, `:242` — 부스터, `:291` — 결과.
- 문서의 메서드명과 수치를 우선 식별자로 사용한다. 줄 번호는 작성 시점 기준이다.

## 2. 좌표와 배율

기준 화면은 1600 × 900. 원점은 왼쪽 위이고 단위는 기준 화면의 px이다. 표의 Rect는 (x, y, width, height) 순서다.

```
s = min(Screen.width / 1600, Screen.height / 900)
W = Screen.width / s
H = Screen.height / s
실제 화면 Rect = 기준 Rect × s
```

현재 코드는 GUI.matrix에 배율만 적용한다. 가운데 정렬용 평행이동이나 레터박스는 없다. 왼쪽 패널은 고정 x, 오른쪽은 W 기준, 하단은 H 기준, 중앙은 W/2·H/2 기준을 유지한다.

| 화면 | s | W × H |
|---|---:|---|
| 1600 × 900 | 1 | 1600 × 900 |
| 1280 × 720 | 0.8 | 1600 × 900 |
| 1920 × 1080 | 1.2 | 1600 × 900 |
| 2560 × 1080 | 1.2 | 2133.33 × 900 |
| 1280 × 1024 | 0.8 | 1600 × 1280 |

16:9 화면에서는 바깥 여백 32px, 헤더 상단 26px를 기본으로 한다. 긴 한국어 문자열은 해당 Rect 안에서 확인한다. 32px Bold 제목은 러너 패널의 기존 예처럼 높이 44px를 확보한다.

## 3. 색상

색상은 현재 코드의 Color 리터럴을 기준으로 한다. HEX는 반올림한 RGB 참고값이고, 구현은 원래 float 값을 유지한다.

| 토큰 | RGBA | HEX 참고 | 용도 |
|---|---|---|---|
| Ink | (0.025, 0.055, 0.08, 0.94) | #060E14 / 94% | HUD·로비 패널, 선택 행의 글자 |
| Mint | (0.43, 1, 0.8, 1) | #6EFFCC | 선택·진행·주요 행동·부스터 |
| White | (1, 1, 1, 1) | #FFFFFF | 제목·본문 |
| Muted | (0.58, 0.71, 0.75, 1) | #94B5BF | 보조 안내·기록·잠금 글자 |
| Slate | (0.2, 0.3, 0.33, 1) | #334D54 | 빈 게이지·잠긴 선택 행 |
| Coral | (1, 0.36, 0.3, 1) | #FF5C4D | 실패·피격 |
| Lobby background | (0.04, 0.07, 0.1, 1) | #0A121A | 로비 바탕 |
| Idle row | (0.08, 0.13, 0.16, 1) | #142129 | 선택되지 않은 메뉴 행 |

선택된 활성 행은 Mint 바탕 + Ink 글자. 잠긴 항목은 '(잠김)' 문구를 함께 표시한다. 선택 중인 잠금 행은 Slate 바탕 + Muted 글자다. 색만으로 잠금이나 실패를 전달하지 않는다. 주요 버튼은 Mint, 결과의 로비 복귀 버튼은 기존 Muted를 쓴다.

## 4. 글꼴과 크기

현재 글꼴 생성은 Malgun Gothic → Arial 순서의 OS 동적 폰트다. 새 폰트 파일이나 TMP·Canvas 전환을 전제하지 않는다. 스타일은 GUI.skin.label 기반, padding 0을 유지한다.

### M2-c 설정 화면에 맞춘 배치

2026-10-20 조회한 SettingsOptions 순서: 전체 볼륨 / 음악 / 효과음 / 속도 시야 효과 / 조작 키. 기존 선택 행을 그대로 사용하면 y = 170, 254, 338, 422, 506이고 마지막 행은 y 574에서 끝난다. 안내 영역(y 730)과 겹치지 않는다.

값은 기존 기록 영역(x 330, width 336)에 오른쪽 정렬한다. 숫자 단계, '켬 / 끔'은 구현된 SettingValue 표시를 따른다. 볼륨의 저장·동작·기본값은 구현 담당 영역이다.

조작 키 페이지는 제목 (70, 168, 600, 36), 각 안내 줄 (70, 226 + 44i, 620, 30). 현재 8줄의 마지막은 y 534~564다. 긴 그래플 안내를 620px 너비에서 확인한다.

후속 디자인 제안: 설정 페이지에서는 하단 안내를 '↑ / ↓ 선택 · ← / → 변경 · ENTER 결정 · ESC 뒤로'처럼 실제 지원하는 키와 일치시키면 값 변경 방법을 더 쉽게 알 수 있다. 이는 문구 제안이며 이 작업에서 코드를 수정하지 않는다.

## 9. 화면 확인 항목

이 절은 디자인 확인 목록이며 실행 결과가 아니다.

- 1600 × 900 및 1280 × 720에서 한국어, 러너 이름, 결과 제목의 하단이 잘리지 않는지.
- Settings 5행, 조작 키 8줄, 트랙 기록과 항목명이 겹치지 않는지.
- 선택된 행의 값도 Ink로 바뀌어 Mint 배경에서 읽히는지.
- 21:9 화면에서 오른쪽 패널은 오른쪽, 중앙 HUD는 가운데를 유지하는지.
- 주행 중 장식과 러너의 발광이 LINK·POLE·부스터 표시를 가리지 않는지.
- 타이틀 → 로비 → 레이스 → 결과 → 로비의 실제 화면 캡처로 확인할 것.

**화면 검증 안 됨.** 문서의 Rect·색·글꼴은 소스 조회 근거다. Play 모드·테스트 실행은 사용자의 '재개' 뒤에 수행하고 별도 보고한다.
